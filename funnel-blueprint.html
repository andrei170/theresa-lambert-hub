What's broken

  • TWO domains routing the same founder to two different front doors with no bridge between them (Bottleneck 1)
  • EIGHT+ named programs with no visible $entry → $mid → $high ladder (Bottleneck 2)
  • ZERO flagship VSL on either site (Bottleneck 3)
  • LinkedIn cadence consistent but long-form thought-leadership ghostwriting under-built (Bottleneck 4)
  • Lead magnet / opt-in is not the front-and-centre route on either site
  • Cross-sell between coaching graduates and consulting candidates is structurally invisible

Phase Map

Phase 1 · Days 1-3 · Consolidation + Hero VSL

  • Day 1: domain consolidation decision locked. theresalambertcoaching.com becomes canonical (or unified theresalambert.com). 301 redirect from theresalambertconsulting.com.
  • Day 1: brand colours locked (teal #106478 primary, forest green #0a7e62 secondary).
  • Day 2: consolidated homepage live with two tracks visible, hero VSL placeholder (using podcast video clip as Day-1 stand-in).
  • Day 2: 3-question diagnostic quiz live (Typeform or ScoreApp).
  • Day 3: hero VSL recorded and embedded. Cormorant Garamond serif overlays. Hospitality-elegance register.

Phase 2 · Days 4-7 · Ladder + Email Layer

  • Day 4: entry-tier page live (The Way to $100K). Stripe + auto-delivery + email trigger.
  • Day 5: mid-tier page live (Your First 100k Mastermind). Application form + discovery call funnel.
  • Day 6: high-tier pages live (1:1 ASCENT + Fractional COO Consulting). Both application-only.
  • Day 7: email welcome flow + tier-specific nurture sequences activated.

Phase 3 · Days 8-30 · Content + LinkedIn Compound

  • LinkedIn cadence ramps from current rhythm to 4-5x/week.
  • YouTube long-form launches with 1x/week podcast repurposes.
  • Bespoke program VSLs re-shot (replacing Day-1 hero recuts).
  • First quarterly Mastermind cohort opens enrollment under the new ladder.

Phase 4 · Days 31-90 · Scale + Iterate

  • LinkedIn cadence locked at 4-5x/week.
  • YouTube to 2x/week.
  • First Fractional COO B2B engagement booked through LinkedIn-sourced inbound (target).
  • Newsletter list crosses Day-1 baseline by 2-3x.
  • Iterate quiz routing logic based on first 90 days of data.

Tech Stack

Core stack (recommended, install Day 1)

  • Website / hosting: Webflow or Framer (current sites likely WordPress, migration as part of consolidation if Theresa wants the speed lift). Or keep WordPress if existing infrastructure is preferred, the consolidation works either way.
  • Email + automation: Kit (ConvertKit) or ActiveCampaign. Welcome flow + tier-specific nurture lives here.
  • CRM: ConvertKit tags or a light CRM (Notion + Zapier OK for first 90 days, upgrade if volume demands).
  • Diagnostic quiz: Typeform or ScoreApp. Output routes to tier-specific landing page + tags the email subscriber.
  • Payments: Stripe direct on entry-tier. Stripe Checkout / invoiced for mid + high tier.
  • VSL hosting: YouTube unlisted embed (with chapter markers) or Vimeo if Theresa prefers gated viewing.
  • Calendly or SavvyCal: for discovery call booking on mid + high tier.

Existing assets to keep

  • Podcast hosting (Spotify, Apple, RSS)
  • IG handles (consolidate to one primary, redirect secondary if needed)
  • Facebook page (low priority)
  • LinkedIn profile (no change to URL, only the cadence shifts)
  • Brainz Magazine column (no change)

Integration Points

  • Domain consolidation: 301 redirect from theresalambertconsulting.com to canonical (likely theresalambertcoaching.com). Preserve all existing inbound SEO juice.
  • Quiz to email: Typeform / ScoreApp output passes tier tag to email platform via Zapier or native integration. Triggers tier-specific welcome.
  • Entry tier purchase to mid tier nurture: Stripe webhook fires "completed entry tier" tag in email platform. Day-14 sequence presents Mastermind invitation.
  • Mid tier enrollment to high tier nurture: Mastermind completion fires tag. Six months post-completion, ASCENT + Fractional COO invitation lands.
  • LinkedIn to funnel: soft CTAs in posts route to entry-tier landing or to the diagnostic quiz. Direct DM inbound from posts gets manually qualified to mid/high tier.
  • Podcast to funnel: each episode's show notes reference the lead magnet or the entry tier offer. Mid-show CTA reads: "If you want the operator cadence I'm describing, it's installed inside Your First 100k Mastermind."

What Stays In Phase 5+ (Post-Install)

These are scale layers that run on Theresa's timeline, not the 7-day install clock:

  • Paid traffic. Pixel + GA4 + Meta retargeting installed Day 1 as infrastructure; cold campaigns turn on once organic ladder is converting.
  • Affiliate / referral program for Mastermind alumni.
  • Annual Tulum Retreat sold to the consolidated list.
  • New entry-tier products tested behind the diagnostic (the quiz architecture supports adding more entry options without breaking the ladder).
  • International expansion of Fractional COO consulting (Vancouver, Toronto, US west coast).

Risk Register

  • Domain migration risk: SEO juice loss if 301s aren't done cleanly. Mitigation: handle in Phase 1, audit redirects on Day 3.
  • Brand fragmentation residual: existing inbound links to old programs need to redirect to the new ladder. Audit all backlinks during Day 1-3.
  • Email list merge: if the two surfaces have separate lists, merge logic needs to be clean. Tag, dedupe, segment by historical engagement.
  • Existing client communication: active 1:1 clients and current Mastermind cohort need a heads-up email before the public-facing brand consolidates. Phase 1 Day 0 task.
  • VSL recording delay: if Theresa can't record in Days 1-3, the podcast video clip placeholder holds the slot. Bespoke VSL ships in Phase 3.
